UGC Poster

A private publishing tool operated by Isaiah Choy.

UGC Poster is a small, private tool that publishes short vertical videos (Reels, YouTube Shorts and TikTok videos) to social media accounts that are owned and operated by Isaiah Choy. It is not offered to the public and does not accept sign-ups.

What it does

  • The owner adds finished videos, captions and posting times to a private schedule.
  • At the scheduled time, UGC Poster uploads the video to the owner's own accounts using each platform's official API (Instagram Graph API, YouTube Data API v3, TikTok Content Posting API).
  • It records whether each post succeeded and the link to the published post.

Platforms

▶
YouTube — publishes the owner's YouTube Shorts using YouTube API Services. YouTube Terms of Service · Google Privacy Policy · UGC Poster Privacy Policy
Instagram & Facebook — Reels via the Instagram Graph API.
TikTok — via the TikTok Content Posting API.

What it does not do

  • It does not access, read or post to anyone else's accounts.
  • It does not read messages, followers or other people's content.
  • It does not sell, share or advertise with any data.
